# ☁️ Cloud-Based Volunteer Coordination System (CBVCS)

A web-based volunteer management and coordination system developed to simplify the process of **volunteer registration, event management, task assignment, communication, attendance, feedback, notifications and reporting**.

The system provides separate interfaces for **Administrators and Volunteers**, allowing efficient coordination of volunteers and events through a centralized platform.

---

## 📌 About the Project

The **Cloud-Based Volunteer Coordination System (CBVCS)** is designed to reduce the difficulties of manually managing volunteers and social events.

The system allows administrators to manage volunteers, create events, assign tasks, monitor volunteer activities and generate reports.

Volunteers can register, maintain their profiles, view and register for events, check assigned tasks, communicate with administrators, submit feedback and track their activities.

---

## 🎯 Objectives

- To develop a centralized volunteer coordination platform.
- To simplify volunteer registration and management.
- To provide efficient event management.
- To assign and monitor volunteer tasks.
- To maintain attendance and feedback records.
- To improve communication between volunteers and administrators.
- To provide notifications for important activities.
- To generate volunteer and event reports.
- To reduce manual paperwork and administrative effort.

---

## 👥 User Modules

### 👨‍💼 Admin Module

The administrator can:

- Admin Login
- View Admin Dashboard
- Manage Volunteers
- Approve Volunteer Registrations
- Create Events
- Manage Events
- Create and Assign Tasks
- Track Task Status
- Manage Notifications
- View Volunteer Feedback
- Manage Attendance
- Communicate with Volunteers
- Generate Event Reports
- Generate Volunteer Reports

### 🙋 Volunteer Module

Volunteers can:

- Register an Account
- Login
- Manage Profile
- View Available Events
- Register for Events
- View Assigned Tasks
- Update Task Status
- Mark/View Attendance
- Submit Feedback
- Receive Notifications
- View Reports
- Communicate with Admin
- Use Volunteer Chat
